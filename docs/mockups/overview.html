One rulebook, three homes

Architecture

The rules live in a pure Dart package with no UI and no networking. The Flutter app runs it for offline play; the server runs the same package to validate every online move — so nobody's client can cheat, and offline and online games can never disagree.

Roadmap

  1. SkeletonFlutter app boots on all five targets; CI builds each platform.
  2. EngineClassic rules in pure Dart, fully unit-tested, deterministic replays.
  3. Local playBoard UI, dice and token animations, pass & play, save/resume. First playable release.
  4. AI opponentsHeuristic AI — capture > progress > safety — at three difficulty levels.
  5. Custom rulesRule configs in the engine, presets, builder UI, shareable codes.
  6. Online coreGuest auth, private rooms with codes, server-authoritative matches.
  7. Online socialRandom matchmaking, friends and invites, reconnect handling.
  8. Polish & shipThemes, sound, languages; Play Store, App Store, web deploy, Windows & Linux packages.
